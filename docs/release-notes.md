**Route Guard 1.2.5**：修复高负载下读取超时误关闭，以及阻止空闲睡眠的问题。

### 本版变化

- 控制接口或本地状态读取失败保持黄灯并继续重试，即使连续超过 15 秒，也不会仅据此关闭受管理进程。
- 读取失败或过期后的缓存不再作为新的自动关闭依据。实际确认的 TUN 关闭、模式错误、规则直连、本地代理入口拒绝连接等风险仍执行保护。
- 提高关键检查与采样队列的 QoS，守护进程使用 Standard 类型。核心分配仍由 macOS 决定。
- 菜单栏应用改用允许空闲睡眠的活动选项，退出时释放活动；后台运行不再主动阻止系统空闲睡眠。
- 增加长时间规则读取超时、多个接口同时超时、失效风险缓存与真实故障的隔离回归验证。

### 支持与使用

macOS 26+、Apple Silicon / arm64，需要 Clash Verge Rev / mihomo、TUN、rule 模式与一个 Selector。组名可自定义，规则目标需与 Route Guard 选定的组一致。

新安装默认只观察；升级保留已有设置、节点确认和保护开关。睡眠时暂停采样，唤醒后恢复。黄色的读取失败表示状态未确认，不代表已经确认代理安全。

本次 GitHub 发布只提供源码和安装包，不会自动替换或重启已安装的应用、服务，也不改动本机代理配置或网络设置。安装或升级后修复才会生效。

### 使用说明

- ad-hoc 签名，尚未进行 Developer ID 签名或 Apple 公证。
- 安装器加载的 PF 规则阻断系统全局 IPv6 出站（loopback、link-local、multicast 除外），与进程保护开关独立。
- 保护只覆盖运行期间的检查，无法保证首包防泄漏。连接审计问题只提示。
- 自动验证只使用临时配置、模拟 API 和一次性测试进程。
