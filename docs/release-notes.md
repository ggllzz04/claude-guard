**Route Guard 1.2.4**：目标策略组支持自定义。

### 本版变化

- 在「设置 → 目标策略组」选择已有 Selector，或输入完整名称后点击「应用策略组」。`🤖 AI` 保留为默认值。
- 规则检查、节点解析、连接审计与可选出口探测统一跟随所选组名。
- 切换策略组自动暂停保护并清除旧节点确认。确认新规则和节点后，再按需开启保护。
- 拒绝不存在的组、非 Selector 或无法确认的列表；旧版本设置继续保留默认组及已有批准。
- 更新 README 和通用 Merge 模板说明，增加自定义组的单元测试与隔离服务回归。

### 支持与使用

macOS 26+、Apple Silicon / arm64，需要 Clash Verge Rev / mihomo、TUN、rule 模式与一个 Selector。组名可自定义，规则目标需与 Route Guard 选定的组一致。

下载 DMG，将 Route Guard 拖到「应用程序」，打开后按需初始化或升级。新安装默认只观察；升级保留已有设置。改变目标策略组后需重新确认节点。

应用中的组名设置只改变检查目标。使用 `config/RouteGuard.yaml` 时，请将模板内所有 `🤖 AI` 规则目标替换为你的实际组名；出口探测需要单独的显式分流规则，模板提供注释示例。

### 使用说明

- ad-hoc 签名，尚未进行 Developer ID 签名或 Apple 公证；首次启动请按 macOS「隐私与安全性」提示处理。
- 安装器加载的 PF 规则阻断系统全局 IPv6 出站（loopback、link-local、multicast 除外），与进程保护开关独立。
- 保护只覆盖运行期间的检查，无法保证首包防泄漏。连接审计问题只提示。
- 自动验证使用隔离 mock；本次发布不安装或升级本机服务，不改动正在使用的客户端或代理配置。
